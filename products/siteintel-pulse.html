01 / OVERVIEW

Two report perspectives from a common evidence model.

The repository describes an Owner Report intended to explain business-facing opportunities and an Expert Diagnostic Workbench for deeper technical findings. The product is still in development. Its GitHub Pages address is a static design/documentation showcase and does not let visitors run the complete scanner.

Who it may suit

Website owners seeking an understandable audit summary, and technical specialists or agencies who need more detailed diagnostics and remediation planning once a full service is released.

02 / DOCUMENTED CAPABILITIES

What the project describes

  • An Owner Report and an Expert Diagnostic Workbench are described in the README.
  • The documented assessment catalogue includes 56 rules across technical health, SEO, performance, accessibility, security, trust and conversion topics.
  • The repository describes crawl inventory, remediation planning, CSV exports and PDF reports.
  • These features are planned/documented scope; availability through a production public scanner is not verified.

Evidence source: SiteIntel Pulse repository README at commit 52b4f1b9ef3807b730ff3f9c3e491cbff26fbb54. The README contains 'public live platform' language; the agency's approved readiness register controls this listing and classifies the full scanner as in development.

03 / AVAILABILITY & LIMITATIONS

Static showcase only; full scanner is not advertised as live.

The linked GitHub Pages site is a static design showcase and documentation preview. A separate Node.js host is required for the full interactive scanner. No public production scanner URL or customer onboarding flow has been verified.

  • Do not submit customer URLs or data to the showcase expecting a completed scan.
  • No public tenant, guest-session or report delivery service is promised by this listing.
  • The README's test counts and feature claims have not been independently re-run as part of this marketplace page.

04 / DATA & SECURITY NOTES

Data handling boundaries

The README describes guest-session isolation, rate limits and persistent scan/report data. These claims have not been independently re-tested for this marketplace listing. No customer data retention, deletion or production privacy commitment is approved while the full scanner remains in development.

04 / REQUIREMENTS

Before using or running it

The static showcase is viewable in a browser. The full scanner requires a separate Node.js host; no customer installation guide or clean external deployment has been approved.

  • The static showcase can be viewed through the linked GitHub Pages destination.

  • No customer installation guide, production deployment endpoint or clean external install has been approved.
